# 쓰지 않는 단어

사용자가 쓰지 말라고 한 단어. 대화·문서·코드 주석·커밋 메시지 어디서든 대체어를 쓴다.

| 쓰지 말 것 | 대신 |
|---|---|
| 고아 (고아 링크 · 고아 노트 · 고아 파일 · orphan) | **미해결 링크** / 미연결 노트 / 미참조 파일 |

- "고아"는 사람에 대한 말이라 기술 용어로 쓰지 않는다 (2026-09-02 지시).
- 옵시디언 UI 원문도 "Unresolved links"라 **미해결 링크**가 원 표기에 더 충실하다.
- **번역 관례로 굳은 표현이라도 되돌리지 마라.** 표준 용어라는 이유로 다시 쓰지 않는다.
- 영어로 답할 때도 같다 — orphan 대신 unresolved / unreferenced.

**예외 — 바꾸면 틀리는 것은 그대로 둔다.** 이건 대체어를 쓰지 않는다.
- **API·식별자·설정 키 이름** — `orphanRemoval`(JPA) · `orphan_cleanup` · `--orphan` 등. 코드에 그렇게 쓰는 이름이라 바꾸면 동작이 달라진다.
- **외부 문서·스펙·에러 메시지 원문 인용** — Cloudflare R2 「Orphan Cleanup」, `ss` 출력의 `orphaned 0` 같은 것.
- **남이 쓴 글** — 다른 사람의 문서·녹취록·PR 제목·자막. 원문은 보존한다.
- **고유명사** — 사람 이름 등(예: 배우 「고아성」). 애초에 이 단어가 아니다.

과거 문서는 소급해 고치지 않는다. **앞으로 내가 쓰는 문장에만** 적용한다 —
다만 사용자가 정리를 요청하면 위 예외를 뺀 **내가 쓴 것만** 바꾼다.
