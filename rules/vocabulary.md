# 쓰지 않는 단어

대화·문서·코드 주석·커밋 메시지 어디서든 대체어를 쓴다.

| 쓰지 말 것 | 대신 |
|---|---|
| 고아 (고아 링크 · 고아 노트 · 고아 파일 · orphan) | **미해결 링크** / 미연결 노트 / 미참조 파일 |

- 「고아」는 사람에 대한 말이라 기술 용어로 쓰지 않는다. 번역 관례로 굳은 표현이라도 되돌리지 않는다.
- 영어로 답할 때도 같다 — orphan 대신 unresolved / unreferenced.

**바꾸면 틀리는 것은 그대로 둔다.**
- API·식별자·설정 키 이름(`orphanRemoval`, `--orphan` 등)
- 외부 문서·스펙·에러 메시지 원문 인용
- 남이 쓴 글(문서·녹취록·PR 제목)
- 고유명사

과거 문서는 소급해 고치지 않는다. 앞으로 내가 쓰는 문장에만 적용한다.
