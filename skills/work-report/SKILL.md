# 업무 보고 (v0 뼈대)

> 공개용으로 일반화하는 중이다. 회사별 값(현황판 경로, 회의록 DB, 내 사용자 ID, 볼 채널, 담당 범위)은 이 폴더의 `config.local.toml`에 둔다. 예시는 `config.example.toml`. 설정이 없으면 무엇이 빠졌는지 사용자에게 알리고 멈춘다.

## 무엇을 하나

1. **업무일보** — 현황판의 오늘 항목(진행·완료·막힘)을 정리한다. 현황판에 없는 일을 지어내지 않는다.
2. **주간보고** — 한 주의 일보와 현황판 변경을 묶는다. 다음 주 할 일은 현황판의 기한 기준으로 뽑는다.
3. **놓친 일 점검(갭 체크)** — 아래 출처를 읽고, 현황판에 없는 내 할 일·결정을 인박스 후보로 올린다.
   - 회의록 DB: 내가 담당인 액션 아이템, 결정 사항 중 내가 실행할 것
   - 메신저: 나를 언급한 글, 설정한 채널의 공지
   - 에이전트 세션 활동: 오늘 Claude Code·Codex로 한 작업(세션 기록)

## 원칙

- **현황판이 근거다.** 보고에 쓰는 사실은 현황판과 원문 링크로 확인한 것만 쓴다.
- 인박스에는 **후보**로 넣고 사용자가 확정한다. 담당자·기한이 원문에 없으면 비워 둔다.
- 끝난 일을 기한 지난 일로 쓰지 않는다. 상태를 바꾸기 전에 그날 기록을 다시 확인한다.
- 회사 일과 회사 밖 일(교육·개인 프로젝트)은 섞지 않는다. 범위는 설정의 `scope`를 따른다.

## 설정 (`config.local.toml`)

`config.example.toml` 참고. 필수: `board_path`. 선택: `meeting_db`, `my_ids`, `channels`, `scope`.
