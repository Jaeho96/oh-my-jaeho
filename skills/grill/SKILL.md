# grill — 실행 전에 요구사항을 뾰족하게

사용자와 같은 그림이 될 때까지 묻는다. 결정은 나무로 본다. 결정 하나에 그 결정에 달린 결정들이 가지처럼 붙는다.

## 라운드로 묻는다

- 이번 라운드에 묻는 것은 「앞선 결정이 다 정해져서 지금 물을 수 있는 질문」 전부다. 아직 열린 질문의 답에 따라 달라지는 질문은 다음 라운드로 미룬다.
- 질문마다 번호와 추천 답을 붙인다. 「네」라고 답하면 추천을 받아들이는 것이 되게 묻는다.
- 한 라운드가 7개를 넘으면 중요한 것부터 나눠 묻는다.
- 답을 받으면 나무를 다시 본다. 정해진 결정이 다음 질문을 연다.

형식(굵게 쓰지 않는다):

```
Q1. <질문 제목>
<질문 내용. 선택지가 있으면 목록으로>
→ 추천: <추천 답과 한 줄 이유>

Q2. …

전부 추천대로면 「네」, 다르면 번호와 답만 주세요.
```

## 사실은 내가 찾고, 결정은 사용자가 한다

- 파일 · 코드 · 데이터 · 문서로 알 수 있는 것은 묻지 않고 직접 찾는다. 오래 걸리면 서브에이전트에 맡기고, 그 결과에 달린 질문만 기다리게 한다. 나머지 질문은 먼저 묻는다.
- 찾은 사실은 근거(경로 · 링크)와 함께 질문에 넣는다. 확인하지 못한 것은 「미확인」이라고 적는다.
- 결정(목표 · 범위 · 우선순위 · 완료 기준 · 누구에게 무엇을 맡길지)은 사용자에게 묻고 기다린다. 담당이나 의도를 추정해서 정하지 않는다.

## 끝내기

- 더 물을 것이 없으면 합의 요약을 보여 준다. 모든 가지를 돌았고 말없이 가정한 것이 없을 때다.
- 합의 요약(두괄식):
  1. 목표 — 한 문장
  2. 완료 기준 — 무엇을 확인하면 끝인가
  3. 범위와 제외
  4. 결정 — 질문 번호와 답
  5. 확인한 사실과 근거, 미확인
  6. 첫 실행 단계
- 사용자가 요약을 확인하기 전에는 실행하지 않는다. 확인하면 요약을 공유 위키 `raw/` 기록으로 남기고 시작한다.
